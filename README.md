# 🎣 わくわくフィッシング大冒険

GitHub Pages対応、海釣り編・川釣り編のブラウザゲーム。iPad Safari対応を意識したCanvas 2D + JavaScriptで、ライブラリ・画像・音声ファイルの外部読み込みは不要です。

## 公開

1. GitHubで新規リポジトリ（例 `fishing-adventure`）を作成。
2. ZIPを解凍し、`index.html`・`style.css`・`game.js`をリポジトリ直下にアップロード。
3. **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**。
4. 数分後に公開URL `https://ユーザー名.github.io/fishing-adventure/` にアクセス。

## ルール

- 海・川それぞれ5ステージ。えさは各ステージ5個。
- えさ・釣りポイントに応じて釣れる魚が変化。フグ・ザリガニは0点。
- キャストすると約2〜3秒後にヒット。リールボタンをタップ。連打で糸のテンションが上がり、放置で逃走ゲージが上がる。
- 各ステージ終了時に累計得点がステージ目標（80,120,160,205,260点）を満たすと次のステージへ。5面クリアでクリア。
- ゲーム開始を1回として、海・川各1日3回。中断・タイトル戻りも1回に含む。
- 各端末のブラウザの`localStorage`とローカル日付を使用。ブラウザデータ削除、別端末、プライベートブラウズ、端末日付変更に対して厳密な制限ではありません。
- ブラウザの音声制限に合わせ、BGMは画面操作後にWeb Audio APIで合成して再生します。BGMは右上のボタンでオン・オフできます。

## 注意

この作品はUNOや市販釣りゲームとは関係のないオリジナル作品です。イラストはCanvas図形と端末搭載絵文字を使っています。古いSafariでは絵文字デザインが異なる場合があります。

## リール操作の難易度（改善版）
釣り上げが難しすぎる問題を修正。デフォルトは「やさしい」で、リールの難易度を「やさしい・ふつう・チャレンジ」から選択できます。タップで魚を引き寄せやすくし、テンションの回復を早め、逃走までの猶予を長くしました。海・川の1日3回制限および進行・スコア・魚図鑑は維持しています。

GitHub上では既存の index.html / game.js / style.css / README.md を更新してください。ブラウザキャッシュが残る場合はSafariを再読み込みしてください。
